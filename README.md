# Simple Alarm App

A minimalist alarm clock web application with a clean and simple UI.

## Features

- ⏰ Simple alarm time setting (hours and minutes)
- 🔔 Web Audio API-based alarm sound
- 🎛️ Easy toggle on/off switch
- 📱 Responsive design for mobile and desktop
- ⏸️ Manual stop button when alarm rings

## How to Use

1. Open `index.html` in your web browser
2. Set the desired alarm time using the hour and minute inputs
3. Toggle the switch to **On** to enable the alarm
4. When the current time matches the alarm time, the alarm will ring
5. Click the **Stop Alarm** button to stop the sound
