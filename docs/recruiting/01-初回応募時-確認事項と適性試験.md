# 01. 初回応募時の返信テンプレート（確認事項・適性試験のご案内）

- **送信タイミング**: 応募が来た直後（最初の一通目）
- **送信チャネル**: Wantedly
- **次のステップ**: 適性試験の提出 → 選考 → カジュアル面談

---

## 本文

株式会社ミズカラ 採用担当でございます。

この度は多くの企業の中から、弊社にご興味をお持ちいただき誠にありがとうございます。
現在、多くの方からご応募をいただいており、カジュアル面談に進む前に いくつかの確認事項と適性試験へのご協力をお願いしております。

【確認事項】
弊社と同業にあたる コーチング関連事業会社 に現在所属、または業務提供されている方（契約形態問わず）は、エントリーをご遠慮いただいております。
同業に該当するか、ご判断が難しい場合はお気軽にお問い合わせください。

-------------------
【質問事項】
以下3点についてご回答ください。

Q1. 日中の稼働は可能ですか？
（平日日中にMTGが発生するためです）

Q2. 東京オフィスへの出社は可能ですか？①または②のどちらかを選択してください。
　　└ ①可能 ②不可 (リモート希望 )
（平日日中に対面MTGが発生する場合もあるためです）

Q3. 弊社の求人に興味を持っていただいた理由を教えてください。

※上記Q1〜Q3へのご回答および適性試験のご提出については、引き続きWantedly上でお願いいたします。
適性試験をご提出いただきましたら、Wantedly上でその旨ご一報ください。

-------------------

【適性試験のご案内】
ミズカラのマーケティング／ライティングポジションでは、
コーチング理解や構造化思考が重要となるため、
選考の前段として 適性試験（Googleドキュメント） を提出いただいています。

試験内容・提出方法につきましては、下記URLの試験シートをご確認ください。

試験URL：https://docs.google.com/document/d/15m3FwcWfB6ZCdR6BiIZRCbNtYh_DEoRodym11zDy9qo/edit?usp=sharing

※ファイルを開いた後、左上「ファイル → コピーを作成」し、
　「ミズカラ_デザイナー試験_お名前」 に変更してご回答ください。

【提出期限】
本日より 1週間以内 を目安にご提出いただけますと幸いです。
ご事情がある場合は柔軟に調整可能ですので、お気軽にご相談ください。

提出いただいた内容をもとに選考を進め、
選考結果および通過された方への次のステップ（カジュアル面談）をご案内いたします。

## 運用メモ

- ファイル名の指定が「ミズカラ_**デザイナー**試験_お名前」となっているが、本文の説明は
  「**マーケティング／ライティング**ポジション」。募集職種ごとに揃えるか要確認。
- 試験URLは閲覧権限（リンクを知っている全員が閲覧可）になっているか、送信前に確認する。
- 提出期限は「本日より1週間以内」。送信日を控えておくと督促の判断がしやすい。
