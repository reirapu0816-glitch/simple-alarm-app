S2

セッション中

IEAR姿勢をベースに、5原則を流れとして実践する。

⚖ コーチング：ティーチング ＝ 7：3 の法則
COACHING 70% — 引き出すターン
問いかけ・深掘り・言語化の確認。受講生に考えさせる。主導権は常に受講生に。
「どう思いますか？」「なぜそう感じましたか？」
TEACHING 30% — 伝えるターン
気づかせた後の手段・知識提供。受講生が「なぜ」を理解してから「どうやって」を教える。
ティーチング過多になる原因
「5回で全部伝えきらなきゃ」という焦り → バトンのイメージで解消。デザインメンターのあなたは次の営業メンターへ渡す人。1ヶ月で全部つくらなくていい。
笑顔でぶっ刺す
肯定しながら課題を明確に伝える手法。「○○さんのこういう良さを知ってるから、こっちの課題が気になるんですよね」。ラポールが気づけていると、指摘の言葉も「私のために言ってくれている」になる。

ラポール形成5原則 — NG / OK 対比
1
受け止める
NG例
「でも頑張れば転職できますよ！」とすぐに励ます。受講生の感情を遮断している。
OK例
「転職できるか不安なんですね。その気持ち、よくわかります。」と感情ラベルをつけて返す。
2
深掘る
NG例
「どんなお仕事をされてるんですか？」と表面的な事実だけ聞く。
OK例
「その仕事、今どんな気持ちでやってますか？楽しいですか？しんどいですか？」と感情・体感を聞く。
3
言語化する
NG例
「なるほど〜」とだけ相槌を打って次の話題へ移る。
OK例
「整理すると、今は○○で悩んでいて、本当はXXしたい、という感じですかね？」と要約して確認する。
4
強みを見つける
NG例
「すごいですね！」と漠然と褒める。根拠がなく伝わらない。
OK例
「6回転職されているということは、環境適応力と決断力がある証拠だと思います。デザインでも活きます。」と具体的に強みを言語化する。
5
未来を見せる
NG例
「一緒に頑張りましょう！」と気合いだけ入れて終わる。
OK例
「3ヶ月後の○○さんが、週5副業案件をこなしている姿を一緒につくりたいです。」と具体的なビジョンを共有する。

耳 見逃しやすい4つの口癖（深掘りサイン）
「でも〜だから無理で」
自己制限思考。マインドブロックの可能性。「その "でも" の前は？」と掘り下げる。
「まあ、なんとかなるかな」
問題の矮小化。ポジティブすぎる場合は具体的リスクを一緒に確認する。
「みんなそうですよね？」
承認欲求・比較依存のサイン。個別フィードバックで差別化する。
「やってみます（即答）」
表面的な同意。本当に理解しているか確認する質問を1つ追加する。
💬 汎用例え話ライブラリ（誰にでも使える3パターン）
🚗 運転免許
「免許を取ったからといって最初から上手く運転できるわけじゃない。練習を重ねることで初めてスムーズに走れる。デザインも同じ。」
→ スキル習得の時間と反復練習の必要性を伝えるとき
💪 筋トレ
「筋肉は1日では付かない。毎日少しずつ続けることで確実に変わっていく。焦らなくていい。」
→ 進捗が遅いと感じている受講生の焦りを緩めるとき
🍑 桃太郎
「桃太郎は仲間を集めながら進んでいく。一人でやろうとしなくていい。グルコン・メンターを仲間として使って。」
→ 孤立傾向・一人で抱え込みやすい受講生に
⚠ 例え話の後は「どう感じましたか？」と必ず相手に言わせて確認する。一方通行で終わらせない。
🧭 受講生の動機タイプ見極め
ワクワク型（目標から入った）
「デザインが好き」「フリーランスになりたい」など前向きな動機が明確。ゴールをより具体的に膨らませる問いかけが有効。
回避型（不安から入った）
「今の職場から逃げたい」「不安で始めた」。否定せず、回避動機の先にある本当の理想を引き出す。焦らせる ≠ 現実を見せる。
振り返り→ロードマップ の順番を守る
ロードマップを先に見せると「こなす」モードに入る。先に「今どんな気持ちか」を振り返らせてから将来像を見せると、言ってることとやってることのズレが本人に見えてきて自己認識が深まる。

S3

悩みのピラミッド診断

受講生の悩みがどの層にあるかを把握してアプローチを変える。

悩みのピラミッド（下から順に深刻）
GOAL / 目的
目標・目的が曖昧 / ズレている

「なぜデザイナーになりたいか」が言語化されていない状態

「○○さんにとって、デザインで何を実現したいですか？」
MEANS / 手段
やり方・ツールがわからない

学習方法・ポートフォリオ・ツールに悩んでいる

「今のカリキュラムで詰まっているところはどこですか？」
RESOURCE / リソース
時間・エネルギー・環境が足りない

学習時間の確保、体力、家庭環境などの現実的な壁

「1週間でどれくらい学習に使える時間がありますか？」
MIND / マインド
自己否定・自信のなさ・恐れ

「自分には無理」「センスがない」という信念レベルのブロック

「どんな場面で一番つらいと感じますか？」
S4

落とし穴チェック

やってしまいがちなNG行動を自覚して避ける。

❌
ピットフォール 1：距離感の誤り（BtoB感）
初回からビジネスライクすぎる話し方・質問をして、受講生が壁を感じる。特に丁寧語だけで進めるとドライに見える。
→ 自己開示・雑談から入り、「一緒にやる人」感を最初の5分で出す。
❌
ピットフォール 2：先生になる（答えを教えすぎる）
「こうすればいいですよ」と正解を渡しすぎて受講生が受け身になる。自己解決力が育たない。
→ 質問で考えさせる。「どう思いますか？」「どうしたいですか？」を先に聞く。
❌
ピットフォール 3：共感しすぎて前に進まない
「そうですよね〜大変でしたね〜」の繰り返しで課題が整理されない。友だちになって終わる。
→ 受け止めた後は「じゃあ次のアクションとして何ができそうですか？」と前進に繋げる。
❌
ピットフォール 4：ポジティブの押しつけ
「大丈夫！絶対できます！」と根拠なく励まして、受講生の不安を無効化する。否定されたと感じる人も。
→ 不安を一旦受け取ってから、根拠ある言葉で肯定する（経験・強みに紐づけた励まし）。
❌
ピットフォール 5：カリキュラム完走だけをゴールにする
「課題を終わらせる」「フィードバックをする」だけになり、受講生の人生・キャリアが見えていない。
→ カリキュラムは手段。「転職後の理想の働き方」を定期的に確認し続ける。
❌
ピットフォール 6：目標金額を否定する・メンターが決める
「現実的に無理ですよ」と言うと受講生の可能性を閉じてしまう。逆にメンターが目標を決めると「あなたが言ったから」という依存が生まれる。
→ 「30万稼ぐために何が必要だと思いますか？」と問いかけ、受講生自身に考えさせる。目標・進捗はすべて受講生が決める。
❌
ピットフォール 7：不安に引っ張られる（ビビる）
受講生の暗い表情・不安な雰囲気に圧倒されてメンターも柔らかくなりすぎる。メンター自身の不安は伝わる。
→ 「やんないと無理ですよ」のスタンスをぶらさない。自信を持って接することが受講生の安心感につながる。ビビった瞬間に主導権が逆転する。
❌
ピットフォール 8：伝え方が「あなたはダメ」になる
課題をストレートに指摘すると受講生が防衛モードに入り、次回から相談しにくくなる。ラポールが崩れやすい。
→「こういう印象を与えてしまうかもしれない、あなたの良さが伝わらなくて私は悔しい」という伝え方。絆奏者として「私はあなたの味方」と伝わる言葉選びをする。
S5

セッション後の振り返り

成功基準と警戒サインで次回の準備に繋げる。

初回1on1 成功基準 — 3つの感情
🤝
受け入れてもらえた
自分の背景・悩みをジャッジなしに聞いてもらえた感覚
💡
理解してもらえた
メンターが自分の状況をわかってくれていると感じた
🚀
一緒にやれる
このメンターと頑張れると思えた。次回が楽しみ。
⚠ 継続ウォッチが必要な警戒サイン
日報の返信率が下がった、または返信が短くなってきた
「大丈夫です」「問題ないです」しか言わなくなった（壁の構築）
セッションでの発言量が急に減った
設定した行動目標を毎回達成できていない（リソース不足 or マインドブロック）
「やっぱり自分には無理かも」という言葉が複数回出た
家族・パートナーとの衝突が増えたと報告があった
Slackの返信がスタンプのみで終わりラリーにならない（受け身・クライアントワークで危険サイン）
グルコンに参加しているが「良さがわからない」と言う（能動的参加ができていない＝受け身思考）
カリキュラムを開いた形跡・言語化シートの提出がない（未読・未学習の見抜きポイント）
TYPE

受講生タイプ別アプローチ

実例ナレッジから抽出した11タイプ。見極めポイントと有効な対応を記載。

TYPE 01
ポジティブ思考強め
⚡ 見極め：「なんとかなりますよ！」「大丈夫です！」が多い
  • 楽観的発言に「そうですね」で終わらせない。「具体的にどうなると大丈夫ですか？」と確認する
  • リスクを否定せず、質問で現実を一緒に確認する（否定するのではなく、解像度を上げる）
  • 「最悪の場合どうなりますか？」と穏やかに聞き、対応策を一緒に考える
  • ネガティブな感情を引き出す質問を意図的に用意しておく
TYPE 02
完璧主義・慎重型
⚡ 見極め：課題提出が遅い、自己評価が低い、「まだ未完成で」が多い
  • 「完成してから見せる」を「今の状態で見せる練習」にシフトさせる
  • 「完璧じゃなくていい」をロジックで伝える（デザイナーは修正が仕事）
  • 小さな完成を積み重ねてもらい、完了体験を増やす
  • 妊娠中・産休明けなど体力・集中力が限られる場合は特に丁寧に
TYPE 03
比較・落ち込みやすい
⚡ 見極め：「他の受講生はもっとできてるのに」「私だけ遅い」が出る
  • 他者との比較から自己の成長軸に視点を移す（「先月の自分と今日を比べたら？」）
  • 強みを具体的に、根拠つきで伝え続ける
  • 「自己嫌悪になるのは真剣に取り組んでいる証拠」とリフレーミングする
  • 日報で小さな前進を毎日見つけてコメントする習慣をつくる
TYPE 04
思考過多・考えすぎ
⚡ 見極め：質問が多い、一つの課題に時間をかけすぎる、理由を求める
  • 思考を止めて「まずやってみる」体験を意図的に作る
  • タイムボックスを設定する（「30分だけやって、出たもので話しましょう」）
  • 「正しいか」より「動かせるか」に評価軸をずらす言葉を使う
  • 「思考している」こと自体は否定せず、出口（行動）を一緒に作る
TYPE 05
学習時間・自己管理に課題
⚡ 見極め：「時間がなくて」が続く、日報が不定期、課題進捗が停滞
  • 時間が「ない」のか「作れていない」のかを分けて把握する
  • 1週間のスケジュールを一緒に確認し、学習できる「隙間」を見つける
  • Slackの使い方・ツール操作で混乱していないか早期確認
  • 週の報告タイミングを固定化して、ペースを外側から構造化する
TYPE 06
安全欲求強め・リスク回避型
⚡ 見極め：変化を嫌う、「本当に大丈夫？」を繰り返す、保険的な選択肢を求める
  • 小さな成功体験を積み重ね、変化への耐性をゆっくり育てる
  • 「最悪の場合でも○○できる」という安全網を言語化して提供する
  • プロセスの予測可能性を高める（次のセッションで何を話すか事前共有）
  • 将来リスク（案件獲得できない/転職が長引く等）を早期に共有しておく
TYPE 07
表情が読み取りづらい・ドライ
⚡ 見極め：カメラオフ、返答が短い、リアクションが薄い
  • 日報を感情の代替情報として活用（内容・文体・送信頻度に注目）
  • 「楽しかったですか？」ではなく「どの部分が面白かったですか？」と具体質問
  • 「何かあればSlackで」ではなく「◯日に進捗確認させてください」と能動的に繋ぐ
  • 文字でのコミュニケーションが得意な場合、日報・Slackでのやり取りを丁寧に
  • 無理にオープンにさせず、安心できる範囲でゆっくり開いてもらう
TYPE 08
40代以降の受講生
⚡ 見極め：キャリアの誇り、プライド、若手扱いへの違和感が見える
  • 「未経験だから当然」という言い方をしない。長年の職業経験を強みとして言語化する
  • タメ口・フランクすぎる言葉遣いは避ける。対等な大人として接する
  • 指摘は「私も似た経験があり〜」と自己開示を交えてから伝える
  • 学習スピードへの焦りを感じていることが多い。速さより確実さを肯定する
  • 「この年齢でもできた実例」を積極的に共有する
  • デジタルツール（Figma・Slack等）に慣れるまで余裕を持ったペース設定を
TYPE 09
男性受講生（BtoB経験者）
⚡ 見極め：論理的・効率重視の発言、感情を表に出しにくい、「手のひら」で話す
  • 「なぜこのアプローチが効果的か」を論理的に説明する（感情訴求だけでは響かない）
  • 効率・コスパの観点からデザイン学習の価値を伝える
  • BtoB感覚（プレゼン・提案書）のスキルをデザインに活かせると伝える
  • 感情の話が出たときは大切にして「その感覚は重要です」と明示的に価値づける
  • ロールモデル戦略：「憧れの起業家ってどう動いてると思う？」と第三者ロールモデル経由で行動を引き出す
  • ブースト戦略：「行けるかもしれん俺」感覚を意図的に作る。論理的な根拠を添えて自信を刺激する
  • 声のトーンを低くハキハキ（柔らかすぎると「考えていない」と思われる）。特にメンターが年下の場合
TYPE 10
ママさん受講生
⚡ 見極め：子供の話題が多い、時間の断片化、「罪悪感」ワード、家事も完璧にしようとしている
  • 子育てとの両立に対して「それは大変ですね」と先に共感する
  • 「家族のためにやっている」という動機を強みとして肯定する
  • 学習できない日があっても責めない。「再開できた」ことを毎回評価する
  • 産休明け直後は特に慎重対応フラグで管理（身体的・精神的に余裕が限られる）
  • 在宅ワーク・フリーランスへの夢を具体的なロールモデルで示す
  • 完璧主義の延長：家事・育児も完璧にやろうとしている可能性がある。「1週間で何時間取れそうか」を聞き、環境・構造の問題かマインドの問題か分ける
  • センシティブトピック（妊娠・出産・子育て）には不用意に触れない。本人が話したら丁寧に受け取る
TYPE 11
効率厨・最短ルート志向
⚡ 見極め：「最速で転職するには？」「これって必要ですか？」が多い
  • 「なぜこのカリキュラムが必要か」を毎回丁寧に説明する（スキップを防ぐ）
  • ショートカット願望に乗らず、基礎の重要性をロジカルに伝える
  • 「急ぎたい気持ち」は否定せず、「急ぐほど基礎が重要」という逆説を伝える
  • 目標から逆算したロードマップを一緒に作り、納得感を与える
TYPE 12
受け身型・与えられ待ち
⚡ 見極め：Slackがスタンプのみ、グルコンの良さがわからない、「入ってみたけど静かだった」
  • Slackラリー診断：返信がスタンプのみで会話にならない → クライアントワークでも同じ対応をする危険サイン
  • グルコン参加しているが「良さがわからない」→ 自発的に何も発信していない＝与えられるもの意識で動いている
  • カリキュラムをクライアントワークとしてロールプレイさせる（「このやり取り、クライアントさんだと思ってやってみて」）
  • 「アクションしてみましたか？」「発言したことありますか？」と問い返し、能動的行動を促す
  • 「こういう対応は印象がどう見えると思う？」と第三者視点で気づかせる（批判ではなくリスクヘッジとして伝える）
  • フリーランサーとして必要な力を一緒に言語化し、「今自分にそれはあるか」を自己評価させる
